# StudentRanking

Java program that finds the top 3 students with the highest grades without using sort().

## Requirements
- Java JDK 25 or newer

## How to run
1. Download the repository as a ZIP file.
2. Extract the ZIP file.
3. Open the project folder in IntelliJ IDEA.
4. Open `src/Main.java`.
5. Run the `Main` class.

## Expected output
```text
TOP 3 STUDENTS
1. Maria - 19.2
2. Ana - 18.5
3. Sofia - 18.5
```
